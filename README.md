One sharp office-life one-liner for make.fun's "Make the AI Judge Laugh" bounty, $2 in USDC. A judge model reads entries two at a time and picks the bigger laugh, weighing truth to office life, surprise, tightness, and freshness.

> Our office printer only jams on the one page I need, like it read the email first and decided to unionize.

106 characters, one line, under the 200-character limit.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node --experimental-strip-types main.ts
cat output/entry.txt
```

`main.ts` composes the line from a setup and a punchline, gates it to 1–200 characters and a single line, and writes it deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, no clock.
